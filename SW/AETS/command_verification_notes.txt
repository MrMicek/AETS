AETS command verification checklist

Below is the list of USB CDC commands to exercise and the expected behavior to confirm the firmware is working.

Help/info
- gh <cmdId>
  Expect: multi-line help text, then "ack gh <cmdId> 0 <timestamp>".
- gi <cmdId>
  Expect: "cmd gi <cmdId> <device info...>" then "ack gi <cmdId> 0 <timestamp>".

Mode control
- mode get <cmdId>
  Expect: "cmd mode <cmdId> <state>" then ack.
- mode set <cmdId> manual
- mode set <cmdId> remote
- mode set <cmdId> test
  Expect: ack with error 0 if transition allowed; a later "evt state <state>" event.

Relay control
- relay get <cmdId>
  Expect: "cmd relay <cmdId> r1 r2 r3 r4" then ack.
- relay set <cmdId> <1-4> <0|1>
  Expect: relay toggles physically; relay state reflects in "relay get" output.
- relay all <cmdId> <r1> <r2> <r3> <r4>
  Expect: all relays change; "relay get" matches.

MOSFET control
- mosfet get <cmdId>
  Expect: "cmd mosfet <cmdId> m1 m2" then ack.
- mosfet set <cmdId> <1-2> <0|1>
  Expect: MOSFET output toggles; "mosfet get" reflects.

Mux control (two channels)
- mux get <cmdId>
  Expect: "cmd mux <cmdId> <mux1> <mux2>" with 0=EXT, 1=INT.
- mux set <cmdId> <1-2> <0|1>
  Expect: selected mux channel switches (LED/measurement change).
- mux all <cmdId> <m1> <m2>
  Expect: both channels switch together.

Current measurement
- curr raw <cmdId> <1-4>
  Expect: "cmd current <cmdId> <raw>" (or equivalent) then ack.
- curr ma <cmdId> <1-4>
  Expect: "cmd current <cmdId> <ma>" (or equivalent) then ack.

Relay counters
- rcnt get <cmdId> [<1-4>]
  Expect: counters for all or single relay.
- rcnt reset <cmdId>
  Expect: counters reset to zero; verify with rcnt get and after power cycle.
- rcnt save <cmdId>
  Expect: counters saved to EEPROM immediately.
- rcnt load <cmdId>
  Expect: counters reloaded from EEPROM (ack error if none stored).

Test control
- test start <cmdId>
  Expect: ack; "evt state TEST"; outputs may follow test sequence.
- test stop <cmdId>
  Expect: ack; "evt state MANUAL" (or previous mode).
- test status <cmdId>
  Expect: "cmd test <cmdId> <mode> <substate> <fault>" then ack.
